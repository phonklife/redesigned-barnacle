Obsidian Vault Integration

This directory also automatically serves as a fully compatible Obsidian Vault. The script generates metadata files for all tracks, motifs, and relationships under the /archive folder in markdown format, complete with bi-directional wikilinks.

archive/Tracks/
archive/Motifs/
virtualluser_music_map.canvas

How to import into Obsidian:

  1. Download the archive/ folder from this repository.
  2. Open Obsidian and select "Open folder as vault".
  3. Select the downloaded archive/ directory.
  4. Enable the Canvas core plugin and open virtualluser_music_map.canvas to explore the dynamic visual network!
